# 🐾 GenshinZMeows

**GenshinZMeows** is a lightweight, desktop application designed to help you manage, analyze, and optimize your Genshin Impact artifacts. 

By importing your `.GOOD` (Genshin Open Object Description) file, the app grades your artifacts, recommends the best pieces for your characters, and helps you plan your builds without needing to log into the game.

---

## ✨ Features

*   **📂 Easy .GOOD File Import:** Instantly load your account data securely and locally.
*   **📊 Account Dashboard:** Get a quick overview of your total characters, weapons, and artifacts owned.
*   **⚔️ Artifact Planner:** Sort and filter your artifacts by specific slots (Flower, Feather, Sands, Goblet, Circlet) to find the best pieces for any character.
*   **📖 Character Builds:**
    *   View recommended Artifact Sets, Weapons, and Constellations.
    *   See your **Best Owned Artifacts** for specific characters, automatically scored based on the optimal main stats and substats.
*   **🔒 100% Private:** All data is processed locally on your computer. No account information is ever sent to a server.

## 📥 Download & Installation

You do not need to build this app from source. You can download the latest ready-to-use installer directly:

1. Go to the **[Releases](../../releases)** tab on the right side of this page.
2. Download the latest **`.msi`** installer (e.g., `GenshinZMeows_x.x.x_x64_en-US.msi`).
3. Run the installer and follow the on-screen instructions.
4. Launch **GenshinZMeows** from your desktop or start menu.

> **Note for Windows Users:** Because this application is independently developed and not signed with a commercial certificate, Windows Defender SmartScreen might show a warning. Click **"More info"** and then **"Run anyway"** to install the app.

---

## 🛠️ How to Use

1. **Get your `.GOOD` file:** You need an exported JSON file of your Genshin inventory. You can generate this using community tools like irminsul or any OCR app
2. **Launch the App:** Open GenshinZMeows.
3. **Upload:** Click the large upload box and select your `.GOOD` file.
4. **Explore:** Use the sidebar to navigate between the Dashboard, Artifact Planner, and Character Builds.
